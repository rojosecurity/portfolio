1. Qué es lo que debes saber antes de

Evento: Un evento es cualquier acción que sucede en tu red, por ejemplo: Un inicio de sesión, un ping, Autenticación de Windows
Alerta: Una alerta es una notificación que se genera cuando se detecta un evento sospechoso o potencialmente malicioso.

Nota de Seguridad: Siempre monitorea las elevaciones de privilegios no autorizadas en cuentas de servicio con permisos de Domain Admin.

2. Eventos clave a monitorear

Para identificar estas actividades en Windows, los registros de auditoría de seguridad son fundamentales. A continuación se presentan los Event IDs prioritarios:

  • Event ID 4624: Inicio de sesión exitoso (Prestar atención a logon type 3 y 10).
  • Event ID 4625: Fallo en el inicio de sesión (Indicador de fuerza bruta o Password Spraying).
  • Event ID 4768: Solicitud de Ticket Granting Ticket (TGT) en Kerberos.

3. Regla de Detección (Ejemplo de Configuración)

A continuación se muestra un fragmento de regla XML personalizable para entornos SIEM (como Wazuh) enfocada en detectar múltiples fallos de autenticación: 

<rule id="100050" level="10">
  <if_sid>18100</if_sid>
  <field name="win.system.eventID">^4625$</field>
  <description>Posible ataque de Password Spraying detectado</description>
  <mitre>
    <id>T1110.003</id>
  </mitre>
</rule>

4. Medidas de Mitigación (Hardening)

Para prevenir la explotación efectiva de estas vulnerabilidades tácticas, se recomienda implementar las siguientes directivas de grupo (GPO):

  1. Habilitar Credential Guard en Windows 10/11 y Windows Server.
  2. Restringir el uso de protocolo NTLM mediante políticas de restricción de autenticación.
  3. Configurar arquitectura LAPS (Local Administrator Password Solution) para rotar claves locales.
Recurso adicional: Puedes consultar la matriz MITRE ATT&CK T1110 para profundizar en las técnicas de acceso a credenciales.
